专注模式 Focus Mode 默认
定义
全局菜单常驻左侧，右侧单一内容区，随时可切模块。
识别
240px 菜单一直在 + 右侧内容区滚动
代码落点
普通路由，不声明 immersive
旧称
常规页、主菜单模式
避免
不要叫「二级菜单」；不要把全屏画布塞进来
沉浸模式 Immersive Mode
定义
隐藏全局菜单，模块自持整屏，画布或编辑区是主角。
识别
全局菜单消失 + 左上「返回主站」
代码落点
meta.immersive = shell / inline
旧称
沉浸式工作区、旧注释里的「专注模式」
避免
不要叫「弹窗 / 抽屉」——它是可深链的整屏路由态

整体架构

文档内容直接读仓库里的 docs/wiki/*.md，后端以无缓存方式挂载，前端 cache: 'no-store' 拉取。改一个错别字，刷新页面就变了，不需要重新构建、不需要重启服务。

三条管道

内容真相源为什么不会过期
规则rules.json页面直接读同一份数据
组件目录扫描多出来的文件自动告警
文档docs/wiki/*.md无缓存挂载，改文件即生效

为什么不用文档站

因为两份必然分叉。文档站一旦独立部署，它就再也跟不上代码了——不是没人维护，是维护它的人看不到代码变更。
