## 保鲜规则

- 改了模块、顶层目录或分层 → **同一个任务内**更新对应页，文档没跟上视为任务未完成。
- 新增一篇 Wiki → 在 `keel/wiki.json` 加一行，否则页面看不到。
- 贴真实实现用引用式内联（见 `keel/references/wiki.md`），不要手粘贴代码。
