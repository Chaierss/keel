# 前端代码地图

## 目录职责

| 目录 | 管什么 | 备注 |
|---|---|---|
| `src/components/ui` | 基础组件，统一出口 `ui/index.ts` | 页面禁止直接 import 第三方 UI 库 |
| `src/components/patterns` | 复合业务组件 | 只组合 ui 层 |
| `src/components/visualization` | 图表、画布类 | 与业务数据解耦 |
| `src/views` | 页面 | 只组合组件，不写数据访问 |
| `src/stores` | 全局状态 | 按领域拆分，禁止巨型 store |

## 组件准入

- 新增共享组件：先登记 `keel/components.json`，再在同目录加 `同名.demo.*`。
- 目录里有、注册表没有 = 构建告警；已登记却零引用 = 候选下架，先标 `deprecated` 再删。
- 组件样式预览来自同目录 demo，不用截图。

## 状态与样式

- 页面级状态留在页面；跨页面共享才进全局 store。
- 主题令牌只有一处定义，组件里不写死颜色与间距。
- 空态、加载态、错误态是组件的三态，不是页面各自补一段。
