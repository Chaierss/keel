# 四件套总纲

四件套不是"四个文档页面"，是**四条从代码到界面的单向管道**。管道断了，页面就是过期副本。

## "自动更新"的三个成立条件

只要缺一条，就退化成手工维护。这三条比选什么技术重要得多。

| 条件 | 含义 | 违反的样子 |
|---|---|---|
| **① 真相源在仓库** | 规则/组件清单/接口定义/wiki 都有唯一落点，且是纯文本可 diff | 规则写在配置中心数据库里，代码仓库看不到谁改的 |
| **② 消费端只读** | 页面直接读真相源，不在中间存一份人写的副本 | 页面上写死一段说明文字，与 JSON 里那条规则内容不一致 |
| **③ 变更无第二步** | 改完源文件，刷新即可见，不需要"点同步 / 跑生成 / 重新构建" | 文档打进前端 bundle，改一个字要重新发版 |

**验收句式**：随便挑一条规则，改掉它 → 刷新页面 → 变了。改的那一刻你没做任何别的事，就算通过。

## 四条管道

```
rules.json      ──import──▶  规则页  ──export──▶  Markdown（给 AI 的上下文）
components/     ──glob───▶  组件页  ──scan────▶  未登记 / 未使用 名单
后端路由+类型   ──gen────▶  接口文档（内嵌 try-it-out）
docs/wiki/*.md  ──mount──▶  Wiki  页（no-store fetch）
```

注意箭头方向全部是**单向**。任何反向（页面里写内容再"导出"到文件）都会产生双写。

## 一张表决定用什么

| 项 | 真相源的形态 | 自动更新机制 | 页面形态 |
|---|---|---|---|
| 规则 | 结构化 JSON（术语 + 规则数组） | 直接 import；派生 Markdown 导出函数 | 左目录 + 右卡片列表，支持复制 AI 上下文 |
| 组件 | 注册表 JSON + 真实组件目录 | 构建期 `import.meta.glob` / `fs.readdir` 扫描比对 | 分层卡片网格 + 内联真实预览 + 三态标记 |
| 接口文档 | 后端路由与模型定义 | 框架自生成 OpenAPI，内嵌 Swagger/Redoc | iframe 内嵌 + 新窗口打开兜底 |
| Wiki | 仓库 `docs/wiki/*.md` | 后端无缓存静态挂载，前端 `no-store` 拉取 | 左目录 + 右 markdown 渲染 |

## 各栈落地对照

同一套约束，换个框架只换实现手法。

| 环节 | Vue/Vite | React/Next | Python/FastAPI | Node/Nest | Go |
|---|---|---|---|---|---|
| 组件扫描 | `import.meta.glob('../../components/**/*.vue')` | 同上（`.tsx`）或 `fs.readdir` | — | — | — |
| 预览内联 | 组件自带 `*.demo.vue` | `*.demo.tsx` | — | — | — |
| 接口文档 | 内嵌后端 `/docs` | 同左 | `FastAPI` 自带 `/openapi.json` `/docs` | `@nestjs/swagger` | `swag` / `humago` |
| Wiki 挂载 | 静态服务器 | 静态服务器 | `StaticFiles(directory=...)` + 禁缓存 | `ServeStaticModule` | `http.FileServer` |
| 禁缓存手法 | `fetch(url, { cache: 'no-store' })` | 同左 | 中间件覆写 `Cache-Control: no-store` | 同左 | 同左 |
| 模式判定 | `import.meta.env.VITE_APP_MODE` | `NEXT_PUBLIC_APP_MODE`（构建期） | `settings.APP_MODE` | 环境变量 + 启动日志 | `ldflags` 注入 |

> 只有"Vue/Vite"这一列写了 `import.meta.glob`——**其他框架不要硬套**。扫描逻辑应该放在构建脚本或体检脚本里，用 `fs` 读目录，框架无关。

## 页面外壳长什么样

四件套共享同一个外壳，别各写一套：

- **入口**：左下角账号菜单 →「系统设置」，不是顶栏一级菜单（它是给项目维护者用的，不是业务功能）。
- **形态**：进入后隐藏全局菜单，模块自持左栏导航（240px），顶部「返回主站」文字出口。
- **切换**：`?tab=rules` 深链驱动，配合 `<KeepAlive>` / 状态保留，切 tab 不丢筛选。
- **权限**：容器不挂权限，**每个 tab 各自声明**。文档类通常无权限要求，配置类要 `config:view`。

骨架见 `templates/SettingsConsole.skeleton.vue`。

## 判断"够不够"的四个反问

1. 换了技术栈，这四条管道还成立吗？（只换实现手法 = 成立；要重写设计 = 你做成了框架特性）
2. 新人只读四件套，能不能不问你就能加一个组件？
3. 三个月后代码大改，四件套会不会自动跟着变？
4. 线上形态下，四件套会不会泄露内部结构？

四个都是"能"，才算装完。
